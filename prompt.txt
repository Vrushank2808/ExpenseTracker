# EXPENSE TRACKING MANAGEMENT SYSTEM

## Flask + Python + SQLite + Modern Minimalistic UI

I am building a complete **Expense Tracking Management System** using Python and Flask.

This is a portfolio/learning project, so I want the application to be **properly structured, maintainable, responsive, secure, and visually polished**, rather than being a basic CRUD application.

I have **already created the project folder structure** and **already installed the required Python libraries**.

Do NOT unnecessarily recreate, rename, or restructure my existing project.

The application must use a **local SQLite database** stored inside the project itself.

Use the following stack:

### Backend

* Python
* Flask
* Flask-SQLAlchemy
* Flask-WTF
* WTForms
* Flask-Login

* python-dotenv

### Database
