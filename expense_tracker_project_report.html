Project Report

Paisa Expense Tracker

A Flask-based expense management application for recording expenses, organizing categories, managing budgets, and viewing financial summaries.

Technology: Python, Flask, SQLAlchemy, SQLite, HTML, CSS, and JavaScript
Repository: ExpenseTracker

1. Introduction

Paisa Expense Tracker is a web application designed to make personal expense management simple and organized. Users can create an account, record daily expenses, assign expenses to categories, choose a payment method, and review their spending from a personal dashboard. The application also supports budget records and financial reports so users can understand their spending over time.

The project is built with Python and Flask using a maintainable application structure. Flask handles routing and request processing, Flask-SQLAlchemy maps application data to a local SQLite database, Flask-Login protects user-specific pages, and Flask-WTF provides form protection. The interface uses server-rendered Jinja templates with custom HTML, CSS, and JavaScript.

Project Goals

  • Provide a secure, user-specific place to manage expenses.
  • Keep data local through an embedded SQLite database.
  • Offer a clean and responsive dashboard experience.
  • Use a modular Flask structure that can be extended later.

Main Features

Authentication
Registration, login, logout, and password updates.
Expense Management
Add, edit, filter, and delete personal expenses.
Categories
Create and manage user-owned expense categories.
Reports
Review monthly and category-wise spending summaries.

def create_app(config_class=Config):
    app = Flask(__name__, instance_relative_config=True)
    app.config.from_object(config_class)

    db.init_app(app)
    migrate.init_app(app, db)
    login_manager.init_app(app)
    csrf.init_app(app)

    with app.app_context():
        db.create_all()
        ensure_category_schema()
        seed_defaults()

    app.register_blueprint(auth_bp)
    app.register_blueprint(main_bp)
    return app

app/models.py - database model
class Expense(db.Model):
    id = db.Column(db.Integer, primary_key=True)
    title = db.Column(db.String(140), nullable=False)
    amount = db.Column(db.Numeric(12, 2), nullable=False)
    expense_date = db.Column(db.Date, default=date.today, nullable=False)
    payment_method = db.Column(db.String(40), nullable=False)
    category_id = db.Column(db.Integer, db.ForeignKey("category.id"), nullable=False)
    user_id = db.Column(db.Integer, db.ForeignKey("user.id"), nullable=False)
app/auth.py - protected login route
@auth_bp.route("/login", methods=["GET", "POST"])
def login():
    email = request.form.get("email", "").strip().lower()
    password = request.form.get("password", "")
    user = db.session.scalar(select(User).where(User.email == email))
    if user and user.check_password(password):
        login_user(user)
        return redirect(url_for("main.dashboard"))
    flash("Invalid email or password.", "error")
    return render_template("auth/login.html")
app/main.py - dashboard route
@main_bp.get("/dashboard")
@login_required
def dashboard():
    today = date.today()
    month_start = today.replace(day=1)
    expenses = db.session.scalars(
        select(Expense).where(Expense.user_id == current_user.id)
    ).all()
    total = sum((item.amount for item in expenses), Decimal("0"))
    return render_template("dashboard.html", total=total)

4. Output: Run and View in Browser

  1. Open PowerShell or a terminal in the project directory.
  2. Install the required Python packages:
    python -m pip install -r requirements.txt
  3. Start the Flask application:
    python run.py
  4. Open the following address in a browser:
    http://127.0.0.1:5000
  5. Register a user account, log in, and use the dashboard to add expenses and view reports.

Expected Browser Output

The browser opens the Paisa Expense Tracker interface. A new visitor is directed to the login page. After registration and login, the dashboard shows the current month's spending, budget information, recent expenses, and navigation to expenses, categories, reports, and account settings.

Database Output

On the first run, the application creates the local database at instance/expense.db. Default categories are seeded automatically. The database remains local and is not connected to an external database service.
